# 🍽️ Zomato Data Analysis | Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on Zomato restaurant data to discover meaningful insights into restaurant trends, customer preferences, ratings, pricing, and online food services. The goal is to transform raw data into useful information through data cleaning, analysis, and visualization.

## 🎯 Project Objectives

- Analyze restaurant distribution across different locations.
- Explore restaurant ratings and customer preferences.
- Understand the relationship between restaurant prices and ratings.
- Analyze online ordering and table booking availability.
- Identify popular cuisines and restaurant categories.
- Discover patterns and trends to support data-driven business decisions.

## 🛠️ Technologies Used

- **Python** – Data analysis and processing.
- **Pandas** – Data cleaning and manipulation.
- **NumPy** – Numerical computations.
- **Matplotlib** – Data visualization.
- **Seaborn** – Statistical data visualization.
- **Jupyter Notebook** – Interactive analysis and documentation.

## 🔍 Project Workflow

1. **Data Loading:** Import the Zomato dataset and examine its structure.
2. **Data Cleaning:** Handle missing values, duplicate records, and inconsistent data.
3. **Data Preprocessing:** Convert columns into suitable formats and prepare the dataset for analysis.
4. **Exploratory Data Analysis:** Analyze restaurant ratings, cuisines, locations, pricing, and service availability.
5. **Data Visualization:** Create charts and graphs to identify trends and patterns.
6. **Insights Generation:** Summarize findings to better understand restaurant performance and customer preferences.

## 📊 Key Analysis Areas

- Restaurant ratings and rating distributions.
- Average cost for two people.
- Popular cuisines and restaurant types.
- Online ordering availability.
- Table booking trends.
- Restaurant distribution by location.
- Relationships between ratings, costs, and service features.

## 💡 Business Value

This analysis helps demonstrate how restaurant data can be used to understand market trends, compare restaurant characteristics, explore customer preferences, and support business decisions. The findings can provide useful direction for restaurant owners, food service businesses, and data analysts.
